# Сейф паролей

Android-менеджер паролей, работающий с файлами **Password Safe v3 (`.psafe3`)** — тем же форматом, что и Password Safe для Windows/Linux/macOS. Одну и ту же базу можно открывать на ПК и на телефоне.

## Возможности

- Открытие и сохранение `.psafe3` из любого места: память телефона, Google Диск, Яндекс Диск, Dropbox, Syncthing и т.д. (через системный выбор файла)
- Просмотр, поиск, группы, создание, правка и удаление записей; история паролей и алиасы Password Safe поддерживаются
- Все поля файла, которые приложение не показывает, сохраняются без изменений — файл остаётся совместимым с Password Safe на ПК
- Автосохранение после каждой правки, резервная копия предыдущей версии файла (10 последних)
- Обнаружение изменений файла с другого устройства: тихая перезагрузка или вопрос при конфликте
- Вход по отпечатку (мастер-пароль хранится в Android Keystore, сбрасывается при добавлении нового отпечатка)
- Автозаполнение логинов и паролей в другие приложения и браузеры
- Буфер обмена помечается как секретный и очищается через заданное время
- Автоблокировка при уходе в фон и выключении экрана, запрет скриншотов
- Генератор паролей и индикатор надёжности
- Нет разрешения на интернет

## Криптография

Формат по спецификации `formatV3.txt`: растяжение ключа SHA-256 (iter ≥ 2048, для новых баз 262 144), Twofish-256 (ECB для ключей K/L, CBC для данных), HMAC-SHA256 по содержимому полей. Twofish и HMAC — из BouncyCastle.

## Сборка

GitHub Actions на каждый push в `main`: юнит-тесты формата, сборка подписанного APK и релиз с файлом APK.
